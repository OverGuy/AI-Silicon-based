# 旅游规划攻略

## 触发条件

用户请求以下内容时使用：
- 旅游规划、旅行攻略、行程规划
- 目的地游玩建议
- X天X夜行程安排
- 旅行住宿/美食/景点推荐

## 输入参数

如未提供，先向用户确认：

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| 目的地 | ✅ | - | 城市或地区名称 |
| 旅行天数 | ✅ | - | 总天数（含往返） |
| 出发日期 | ❌ | 次日 | 行程开始日期 |
| 预算级别 | ❌ | 舒适 | 经济/舒适/豪华 |
| 旅行偏好 | ❌ | 综合 | 文化/自然/美食/休闲/亲子 |
| 同行人数 | ❌ | 未指定 | 影响住宿和交通推荐 |

## 执行流程

### 第一步：信息收集（必须使用网络搜索）

按顺序搜索以下信息，确保数据真实有效：

1. **目的地概览**
   - `[目的地] 旅游攻略 [当前年份]`
   - `[目的地] 必去景点推荐`
   - `[目的地] 当地特色美食`
   - `[目的地] 住宿推荐 [预算级别]`
2. **景点详情**（每个景点单独搜索）
   - `[景点名称] 门票价格 营业时间 [当前年份]`
   - `[景点名称] 需要预约吗`
   - `[景点名称] 游玩时长建议`
3. **美食详情**
   - `[目的地] [美食名称] 推荐餐厅 评分`
   - `[餐厅名称] 地址 人均消费`
4. **住宿详情**
   - `[目的地] [区域] 酒店推荐 [预算级别]`
   - `[酒店名称] 地址 价格`
5. **交通信息**
   - `[目的地] 交通攻略 地铁公交`
   - `[景点A] 到 [景点B] 怎么走`
6. **天气和注意事项**
   - `[目的地] [出发月份] 天气 穿衣建议`
   - `[目的地] 旅游注意事项`

### 第二步：行程规划

规划原则：
1. **地理邻近原则**：将距离相近的景点安排在同一天
2. **时间合理性**：考虑交通时间、游玩时长、休息时间
3. **节奏平衡**：高强度景点和休闲活动交替安排
4. **美食就近**：餐厅选择靠近当天景点

### 第三步：格式化输出

按下方「输出模板」输出完整行程攻略。

## 数据搜索规范

1. **所有数据必须来自网络搜索**，不可凭记忆编造
2. **优先搜索官方渠道**：景区官网、政府旅游网站
3. **权威平台优先**：携程、马蜂窝、大众点评、美团
4. **标注信息来源**：在输出末尾列出参考网站
5. **时效性检查**：门票价格、营业时间等需确认是当前有效信息

## 地理位置优化策略

### 规划前准备
1. 搜索目的地地图，了解各景点分布
2. 将景点按区域分组
3. 规划每日活动区域，减少跨区长距离移动

### 优化原则
1. **同区集中**：同一天的景点尽量在同一区域
2. **路线顺畅**：避免来回折返
3. **住宿选址**：选择交通便利、靠近主要景点区域的住宿
4. **弹性调整**：如遇距离过远，考虑调整顺序或更换交通方式

## 预算级别定义

| 级别 | 住宿/晚 | 餐饮/餐 | 景点偏好 |
|------|---------|---------|----------|
| 经济 | ¥100-300 | ¥30-80 | 免费/低价景点为主 |
| 舒适 | ¥300-800 | ¥80-200 | 热门景点+特色体验 |
| 豪华 | ¥800+ | ¥200+ | VIP体验+私人定制 |

## 特殊情况处理

### 雨天备案
- 搜索室内景点作为备选
- 标注哪些景点受天气影响

### 节假日出行
- 特别提醒预约要求
- 标注可能的拥堵情况
- 建议错峰出行时间

### 亲子游
- 标注适合儿童的景点
- 推荐亲子餐厅
- 提醒携带儿童证件
