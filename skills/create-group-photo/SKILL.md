# 一起来合照吧

使用内置 Image Gen 将一张或多张参考图片中的不同人物自然合成到同一主题场景。默认生成写实、自然摄影风格的 `16:9` 合照。

## 输入约定

收集以下输入：

- 必填：至少一张包含人物的图片。
- 必填：合照主题，例如中秋节、中国长城、海边婚礼或未来城市。
- 可选：画面宽高比；未指定时使用 `16:9`。
- 可选：服装、动作、站位、摄影风格以及禁止修改项。

将“尺寸”默认解释为宽高比。只有缺少人物图片或主题时才询问用户；其余未指定项使用默认值继续。

## 工作流

### 1. 检查参考图片

查看每一张输入图片，建立内部人物清单：

- 记录每张图片中的全部人物以及每人的显著身份特征。
- 将同一人物的多张照片合并为一组身份参考，最终只生成一次。
- 将一张图片中的多个人视为多个不同人物，除非其他参考图片表明其中有人重复。
- 仅在无法可靠判断两张图片是否为同一人物、且判断会改变最终人数时请求用户确认。
- 确保最终人物数等于清单中的不同人物数。

严格保留每人的脸部结构、五官比例、发型、肤色、体型、年龄感和显著特征。允许为适应主题自然调整服装、姿势、视线、表情和站位，但不得使人物无法辨认。

### 2. 解析主题

从主题中提炼少量最有辨识度的元素：

- 环境或建筑；
- 标志性物件；
- 色彩、天气、时段和光线；
- 节日、地域或文化氛围。

让主题元素明确但不遮挡或压过人物。例如中秋节可使用圆月、月饼、灯笼和团圆氛围；中国长城应包含可信的长城建筑与山地环境。避免无关装饰、文字、Logo 和水印。

### 3. 规划自然合照

根据人数和比例安排构图：

- 让所有人物完整、清晰且大小合理；避免遮脸、裁掉头部或产生额外肢体。
- 统一人物与背景的相机视角、透视、焦距、景深、光向、色温、颗粒和清晰度。
- 添加可信的接触阴影、环境反光和遮挡关系，使人物真实站立或坐落在场景中。
- 避免贴图感、悬浮感、剪贴边缘、光晕、重复人物、漏人、脸部混合和比例失衡。
- 除非用户另有要求，采用自然互动的群体姿势，而不是僵硬并排或证件照式构图。

### 4. 组织 Image Gen 提示词

将请求整理为简洁、明确的生成说明，至少包含：

```text
Use case: compositing + identity-preserve
Primary request: 将所有不同人物自然合成为一张主题合照
Input images: 逐张说明人物参考及重复身份关系
Distinct people: 明确不同人物总数，并要求每人恰好出现一次
Theme/background: 主题及其标志性环境和元素
Style/medium: 写实自然摄影，或用户指定风格
Composition/framing: 指定宽高比、人物布局和镜头范围
Identity invariants: 严格保留每人的脸、发型、肤色、体型、年龄感和显著特征
Integration: 匹配光线、透视、色温、阴影、景深和接触关系
Allowed changes: 仅按需要调整服装、姿势、视线和站位
Avoid: 漏人、重复人物、身份混合、额外人物、畸形肢体、贴图边缘、文字、Logo、水印
```

明确说明输入图片是身份与合成参考，不要要求先输出透明抠图。最终成品必须直接由内置 Image Gen 生成；不要使用本地图像拼接脚本、HTML、SVG 或其他生成方式替代。

### 5. 调用 Image Gen

- 所有输入都是本地文件时，将全部文件路径放入 `referenced_image_paths`；不要同时设置 `num_last_images_to_include`。
- 本地图片尚未显示时，先用 `view_image` 检查每一张，再调用 Image Gen。
- 所有输入都来自当前会话时，使用 `num_last_images_to_include`，并设置为能包含全部目标图片的最小数量，最多为 5。
- 不要同时使用 `referenced_image_paths` 和 `num_last_images_to_include`。
- 如果本地路径与仅存在于会话中的图片混用，或超过 5 张会话图片且无法一次覆盖全部目标，要求用户重新附加缺失图片或提供所有图片的本地路径；不要遗漏任何人物继续生成。
- 每次生成一张最终合照。若检查发现明显身份、人数或融合问题，只进行一次针对具体缺陷的重试，并保留所有其他正确部分。

## 质量检查

在交付前逐项检查：

1. 人物清单中的每个不同人物是否恰好出现一次。
2. 每个人是否仍可根据参考图片清楚辨认，且没有脸部或身份相互混合。
3. 主题的标志性元素是否明确、可信且不抢夺人物主体地位。
4. 光影、透视、景深、比例、阴影和人物边缘是否自然融合。
5. 画面宽高比是否符合用户要求，未指定时是否为 `16:9`。
6. 是否没有多余人物、文字、Logo、水印、异常手指或肢体。

## 交付

在最终回复中直接展示生成的合照，并简要说明采用的主题和宽高比。若图片用于当前项目或用户指定了保存位置，将最终图片复制到目标目录，避免覆盖已有文件，并报告绝对路径；预览用途可保留在 Image Gen 的默认输出位置。
